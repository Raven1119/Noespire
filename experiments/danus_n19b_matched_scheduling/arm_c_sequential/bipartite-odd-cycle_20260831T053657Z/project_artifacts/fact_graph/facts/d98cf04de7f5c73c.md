## statement
Let \(G\) be a finite undirected graph. Prove that \(G\) is bipartite if and only if \(G\) contains no cycle of odd length.

## proof
Assume first that G is bipartite. By the definition of bipartite, there are disjoint sets A and B whose union is V(G), such that every edge of G has one endpoint in A and the other endpoint in B. Let (v_0,v_1,...,v_k) be an arbitrary cycle in G, written with v_k=v_0, so that its length is k. Interchange the names A and B if necessary so that v_0 is in A. Because every edge crosses from one bipartition class to the other, induction on i shows that v_i is in A when i is even and v_i is in B when i is odd, for every integer i with 0<=i<=k. Since v_k=v_0 is in A, k is even. Thus every cycle of G has even length, so G contains no cycle of odd length.

Conversely, assume that G contains no cycle of odd length. In every connected component H of G, choose one vertex r_H as a root. For each vertex z in H, let d(z) be the minimum length of a path in H from r_H to z. This minimum exists because H is connected; in particular, the root and every isolated vertex have distance 0 from the chosen root of their component. Define A to be the set of all vertices z of G for which d(z) is even, and define B to be the set of all vertices z of G for which d(z) is odd. Then A and B are disjoint and their union is V(G).

It remains to prove that every edge crosses from A to B. Let xy be any edge of G. Its endpoints lie in the same connected component H. Let P_x be a path of length d(x) from r_H to x, and let P_y be a path of length d(y) from r_H to y. Suppose, for a contradiction, that x and y lie in the same one of A and B. Then d(x) and d(y) have the same parity. Traverse P_x from r_H to x, then traverse the edge xy, and then traverse P_y in reverse from y to r_H. This is a closed walk in G of length d(x)+1+d(y), which is odd. By the verified predecessor fact ec5be0d896864f8c, this odd closed walk contains a cycle of odd length. That contradicts the assumption that G contains no cycle of odd length. Hence the endpoints of every edge lie in different sets A and B. Therefore (A,B) is a bipartition of G, and G is bipartite.

The two implications prove the stated equivalence.

## intuition
A bipartition forces every walk to alternate sides, so a cycle must return after an even number of steps. Conversely, parity of distance from a root gives two candidate sides; an edge inside one side would create an odd closed walk and therefore an odd cycle.
