## statement
Let \(m_1,\ldots,m_k\) be pairwise coprime integers greater than \(1\), and let \(a_1,\ldots,a_k\) be arbitrary integers. Prove that there is an integer \(x\) satisfying
\[
x\equiv a_i\pmod{m_i}\qquad(1\le i\le k),
\]
and that any two such integers are congruent modulo \(M=m_1m_2\cdots m_k\).

## proof
We use Bezout's identity: if two integers have greatest common divisor 1, then there are integer coefficients whose linear combination of those two integers is 1.

For each index i with 1 <= i <= k, define
M_i = product_{1 <= j <= k, j != i} m_j,
where an empty product is 1. We first construct an integer c_i such that
c_i M_i is congruent to 1 modulo m_i.

Fix i. For every j != i, pairwise coprimality gives gcd(m_i,m_j)=1. By Bezout's identity, choose integers r_{ij},s_{ij} satisfying
r_{ij}m_i+s_{ij}m_j=1.
Multiply these identities over all j != i. In the expansion of the product, the term obtained by choosing s_{ij}m_j from every factor is
(product_{j != i} s_{ij}) M_i.
Every other term contains at least one factor r_{ij}m_i and is therefore divisible by m_i. Consequently there are integers A_i and c_i such that
1=A_i m_i+c_i M_i,
where c_i=product_{j != i}s_{ij}. If k=1, the same identity holds by taking M_1=c_1=1 and A_1=0. Thus in every case
c_iM_i is congruent to 1 modulo m_i.

Define E_i=c_iM_i and define
x=sum_{i=1}^k a_iE_i.
For a fixed index l, E_l is congruent to 1 modulo m_l. If i != l, then m_l is a factor of M_i, so E_i is congruent to 0 modulo m_l. Reducing the displayed sum for x modulo m_l therefore gives
x congruent to a_l modulo m_l.
Since l was arbitrary, x satisfies every required congruence. This proves existence.

It remains to prove uniqueness modulo M. Let x and y be any two integers satisfying all the required congruences, and put d=x-y. For each i, the two congruences modulo m_i imply m_i divides d.

We prove by induction on t, for 1 <= t <= k, that P_t=m_1m_2...m_t divides d. The assertion for t=1 holds because m_1 divides d. Suppose 1 <= t < k and P_t divides d. We first show that P_t and m_{t+1} are coprime. For every j with 1 <= j <= t, pairwise coprimality and Bezout's identity give integers alpha_j,beta_j such that
alpha_jm_j+beta_jm_{t+1}=1.
Multiplying these t identities, the unique term that contains no factor m_{t+1} is
(product_{j=1}^t alpha_j)P_t,
and every remaining term is divisible by m_{t+1}. Hence there are integers A and B such that
1=AP_t+Bm_{t+1}.

Write d=P_tq, which is possible by the induction hypothesis. Multiplying the last Bezout identity by q gives
q=A(P_tq)+Bm_{t+1}q=Ad+Bm_{t+1}q.
Because m_{t+1} divides d, both terms on the right are divisible by m_{t+1}; hence m_{t+1} divides q. Write q=m_{t+1}h. Then
d=P_tq=P_tm_{t+1}h=P_{t+1}h,
so P_{t+1} divides d. This completes the induction. In particular M=P_k divides x-y. Therefore x is congruent to y modulo M, proving the asserted uniqueness.

## intuition
Pairwise Bezout identities produce one coefficient that selects each residue independently; pairwise coprimality also forces a common multiple of all moduli to be divisible by their product.
