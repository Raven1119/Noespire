## statement
Let \(p\) be a prime and let \(G\) be a finite group of order \(p^n\) for some integer \(n\ge 1\). Prove that the order of the center \(Z(G)\) is divisible by \(p\), and hence that \(Z(G)\) contains a nonidentity element.

## proof
Let \(x\in G\setminus Z(G)\). Define its centralizer by \(C_G(x)=\{g\in G:gx=xg\}\). This is a proper subgroup of \(G\): if \(C_G(x)=G\), then \(x\) commutes with every element of \(G\), contrary to \(x\notin Z(G)\).

Consider the map from the set of left cosets of \(C_G(x)\) in \(G\) to the conjugacy class \(\operatorname{Cl}_G(x)=\{gxg^{-1}:g\in G\}\), defined by
\[
 gC_G(x)\longmapsto gxg^{-1}.
\]
It is well-defined because multiplying \(g\) on the right by an element commuting with \(x\) does not change \(gxg^{-1}\). It is surjective by the definition of the conjugacy class. It is injective because if \(g_1xg_1^{-1}=g_2xg_2^{-1}\), then \(g_2^{-1}g_1\in C_G(x)\), so \(g_1C_G(x)=g_2C_G(x)\). Hence
\[
 |\operatorname{Cl}_G(x)|=[G:C_G(x)].
\]
The left cosets of \(C_G(x)\) partition \(G\), and each has \(|C_G(x)|\) elements. Therefore
\[
 p^n=|G|=[G:C_G(x)]\,|C_G(x)|.
\]
Thus \(|C_G(x)|\) is a divisor of \(p^n\), so \(|C_G(x)|=p^k\) for some integer \(k\) with \(0\le k\le n\). Since \(C_G(x)\) is proper, \(|C_G(x)|<|G|\), whence \(k<n\). Consequently
\[
 |\operatorname{Cl}_G(x)|=[G:C_G(x)]=p^{n-k},
\]
and this is divisible by \(p\) because \(n-k\ge 1\).

Now the conjugacy classes partition \(G\). The conjugacy class of an element \(z\in G\) is a singleton if and only if \(z\in Z(G)\): it is a singleton exactly when \(gzg^{-1}=z\) for every \(g\in G\), equivalently when \(gz=zg\) for every \(g\in G\). Choose representatives \(x_1,\ldots,x_r\) for all non-singleton conjugacy classes, where \(r\) is a nonnegative integer. The resulting class equation is
\[
 |G|=|Z(G)|+\sum_{i=1}^{r}|\operatorname{Cl}_G(x_i)|.
\]
Every summand in the sum is divisible by \(p\), by the argument above, and \(|G|=p^n\) is divisible by \(p\) because \(n\ge 1\). Hence
\[
 |Z(G)|=|G|-\sum_{i=1}^{r}|\operatorname{Cl}_G(x_i)|
\]
is divisible by \(p\).

Finally, \(Z(G)\) contains the identity element \(e\), so it is nonempty. Its positive order is divisible by the prime \(p\), and every prime satisfies \(p\ge 2\); therefore \(|Z(G)|\ge p\ge 2\). Thus \(Z(G)\) contains an element distinct from \(e\), as required.

## intuition
Conjugation partitions G into classes. Central elements give singleton classes, while every other class has size a positive power of p. Reducing the class equation modulo p leaves only the center.
