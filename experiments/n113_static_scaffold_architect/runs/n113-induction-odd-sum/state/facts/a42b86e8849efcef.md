# Statement

For every nonnegative integer k, if 1 + 3 + ⋯ + (2k - 1) = k² (with the sum empty when k = 0), then 1 + 3 + ⋯ + (2k - 1) + (2k + 1) = (k + 1)².

# Proof

Let k be a nonnegative integer and assume that 1 + 3 + ⋯ + (2k - 1) = k². Adding 2k + 1 to both sides gives 1 + 3 + ⋯ + (2k - 1) + (2k + 1) = k² + 2k + 1. Since k² + 2k + 1 = (k + 1)², the desired equality follows.
