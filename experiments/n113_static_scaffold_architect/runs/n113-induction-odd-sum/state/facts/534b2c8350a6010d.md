# Statement

When n = 0, the sum of the first n positive odd integers is the empty sum, which equals 0 = 0².

# Proof

By the definition of an empty sum, the sum of the first 0 positive odd integers is 0. Also, 0² = 0. Therefore the empty sum equals 0 = 0².
