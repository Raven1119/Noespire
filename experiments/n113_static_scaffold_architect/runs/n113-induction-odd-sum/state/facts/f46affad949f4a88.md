# Statement

For every nonnegative integer n, the sum of the first n positive odd integers equals n²; equivalently, 1 + 3 + ⋯ + (2n - 1) = n², with the empty sum interpreted as 0 when n = 0.

# Proof

We prove the statement by induction on n. The base case n = 0 holds because the sum is empty and equals 0 = 0², by Fact 534b2c8350a6010d. For the induction step, let k be a nonnegative integer and assume that the sum of the first k positive odd integers is k². Fact a42b86e8849efcef then gives that adding the next positive odd integer, 2k + 1, produces (k + 1)². Thus the statement for k implies the statement for k + 1. By induction, the equality holds for every nonnegative integer n.
