# Statement

For all real numbers a, b, and c, a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − ac − bc).

# Proof

Let a, b, and c be arbitrary real numbers. Expanding the right-hand side gives (a + b + c)(a² + b² + c² − ab − ac − bc) = a³ + ab² + ac² − a²b − a²c − abc + a²b + b³ + bc² − ab² − abc − b²c + a²c + b²c + c³ − abc − ac² − bc². All opposite terms cancel, leaving a³ + b³ + c³ − 3abc. Hence the stated identity holds for all real a, b, and c.
