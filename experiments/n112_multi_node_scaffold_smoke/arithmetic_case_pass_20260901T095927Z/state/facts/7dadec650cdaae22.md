# Statement

1 + 3 + 5 = 4 + 5.

# Proof

From the accepted fact 1 + 3 = 4, add 5 to both sides. This gives (1 + 3) + 5 = 4 + 5, hence 1 + 3 + 5 = 4 + 5.
