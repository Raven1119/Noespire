## statement
Let \(Q\) be a real \(n\times n\) orthogonal matrix, and let \(u\in\mathbb R^n\) satisfy \(u^{\mathsf T}u=1\). Define
\[
H=I-2uu^{\mathsf T}.
\]
Assume there is no nonzero vector \(v\) with \(Qv=v\). Prove that there is a nonzero vector \(w\) with \(HQw=w\).

## proof
Because \(Qv=v\) is equivalent to \((I-Q)v=0\), the hypothesis says that the kernel of the linear map \(I-Q:\mathbb R^n\to\mathbb R^n\) is \(\{0\}\). A linear map from the finite-dimensional vector space \(\mathbb R^n\) to itself with zero kernel is invertible. Hence define
\[
w=(I-Q)^{-1}u.
\]
Then
\[
(I-Q)w=u,
\]
and therefore
\[
Qw=w-u. \tag{1}
\]
The vector \(w\) is nonzero: if \(w=0\), then \(u=(I-Q)w=0\), contradicting \(u^{\mathsf T}u=1\).

Since \(Q\) is orthogonal, \(Q^{\mathsf T}Q=I\), so
\[
w^{\mathsf T}w=(Qw)^{\mathsf T}(Qw).
\]
Using (1) and \(u^{\mathsf T}u=1\), this equality becomes
\[
w^{\mathsf T}w=(w-u)^{\mathsf T}(w-u)
=w^{\mathsf T}w-2u^{\mathsf T}w+1.
\]
Consequently,
\[
u^{\mathsf T}w=\frac12. \tag{2}
\]
Now (1), (2), and the definition of \(H\) give
\[
\begin{aligned}
HQw
&=(I-2uu^{\mathsf T})(w-u)\\
&=w-u-2u\bigl(u^{\mathsf T}w-u^{\mathsf T}u\bigr)\\
&=w-u-2u\left(\frac12-1\right)\\
&=w.
\end{aligned}
\]
Thus the explicitly constructed nonzero vector \(w=(I-Q)^{-1}u\) satisfies \(HQw=w\), as required.

## intuition
Invert I-Q and apply it to the reflecting normal u. Orthogonality says w and Qw=w-u have the same norm, forcing u to bisect their displacement in exactly the scalar relation needed for the reflection H to send Qw back to w.
