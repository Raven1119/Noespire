## statement
Let (n) be a positive integer. Prove that every sequence of (n^2+1) distinct real numbers contains either a strictly increasing subsequence of length (n+1) or a strictly decreasing subsequence of length (n+1).

## proof
Fix a positive integer n and an arbitrary sequence x_1,x_2,...,x_{n^2+1} of distinct real numbers. For each index i with 1 <= i <= n^2+1, define I_i to be the maximum length of a strictly increasing subsequence whose last term is x_i, and define D_i to be the maximum length of a strictly decreasing subsequence whose last term is x_i. More explicitly, an increasing subsequence ending at x_i is given by indices 1 <= t_1 < t_2 < ... < t_r = i such that x_{t_1} < x_{t_2} < ... < x_{t_r}; its length is r, and D_i is defined in the same way with all value inequalities reversed. Each maximum exists: the one-term subsequence x_i is eligible, and only finitely many index subsequences end at i.

Assume for contradiction that this sequence has neither a strictly increasing subsequence of length n+1 nor a strictly decreasing subsequence of length n+1. If I_i were at least n+1 for some i, the first I_i terms of an increasing subsequence of length I_i would form an increasing subsequence of length n+1. Therefore I_i <= n for every i. The same argument gives D_i <= n for every i. Since the one-term subsequence is both increasing and decreasing, I_i >= 1 and D_i >= 1. Consequently every ordered pair (I_i,D_i) lies in the set {1,2,...,n} x {1,2,...,n}, which has n^2 elements.

There are n^2+1 indices i. Hence, by the pigeonhole principle, two distinct indices have the same ordered pair. Name them i and j with i<j, so I_i=I_j and D_i=D_j. Because all sequence terms are distinct, exactly one of x_i<x_j and x_i>x_j holds.

If x_i<x_j, choose a strictly increasing subsequence of length I_i ending at x_i. Appending x_j is valid because i<j and x_i<x_j, so it produces a strictly increasing subsequence of length I_i+1 ending at x_j. By the definition of I_j as the maximum such length, I_j >= I_i+1. This contradicts I_j=I_i.

If x_i>x_j, choose a strictly decreasing subsequence of length D_i ending at x_i. Appending x_j is valid because i<j and x_i>x_j, so it produces a strictly decreasing subsequence of length D_i+1 ending at x_j. By the definition of D_j, D_j >= D_i+1. This contradicts D_j=D_i.

Both possible comparisons of x_i and x_j lead to contradictions. Thus the assumed absence of both kinds of subsequence is impossible. The arbitrary sequence therefore contains a strictly increasing subsequence of length n+1 or a strictly decreasing subsequence of length n+1.

## intuition
Assign to each position the pair of longest increasing and decreasing subsequence lengths ending there. Earlier and later positions cannot have the same pair, because their distinct values let one of the two endpoint subsequences be extended. If both lengths were at most n, only n^2 pairs would exist for n^2+1 positions.
