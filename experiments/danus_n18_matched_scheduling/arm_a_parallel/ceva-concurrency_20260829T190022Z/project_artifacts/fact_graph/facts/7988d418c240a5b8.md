## statement
Let (ABC) be a nondegenerate triangle, and let (D,E,F) lie in the interiors of (BC,CA,AB), respectively. Prove that the cevians (AD,BE,CF) are concurrent if and only if

\[
\frac{BD}{DC}\cdot\frac{CE}{EA}\cdot\frac{AF}{FB}=1.
\]

## proof
All lengths below are ordinary positive Euclidean lengths. Set
\[
p=\frac{BD}{DC},\qquad q=\frac{CE}{EA},\qquad r=\frac{AF}{FB}.
\]
Because D,E,F are interior points of their respective sides, p,q,r are positive real numbers.

We first establish coordinates without using any concurrency theorem. Since ABC is nondegenerate, the vectors B-A and C-A are linearly independent. Hence every point X in the affine plane has a unique expression
\[
X=xA+yB+zC\quad\text{with}\quad x+y+z=1.
\]
We call (x,y,z) the normalized barycentric coordinates of X.

We compute the side-point coordinates directly from the ratios. For D there is a unique real number t with 0<t<1 such that D=(1-t)B+tC. Then BD=t\,BC and DC=(1-t)\,BC, so p=t/(1-t), whence t=p/(1+p). Thus
\[
D=\frac{1}{1+p}B+\frac{p}{1+p}C.
\]
The same calculation on CA and AB gives
\[
E=\frac{q}{1+q}A+\frac{1}{1+q}C,
\qquad
F=\frac{1}{1+r}A+\frac{r}{1+r}B.
\]

We now characterize each cevian by one coordinate equation. A point X=(x,y,z) lies on the affine line AD if and only if there is a real number \lambda such that
\[
X=(1-\lambda)A+\lambda D.
\]
Using the displayed coordinates of D, this is equivalent to
\[
x=1-\lambda,\quad y=\frac{\lambda}{1+p},\quad z=\frac{\lambda p}{1+p},
\]
and therefore to z=py. Conversely, if x+y+z=1 and z=py, then with \lambda=(1+p)y one has x=1-y-z=1-(1+p)y=1-\lambda and the three displayed coordinate equalities hold. Consequently,
\[
X\in AD\quad\Longleftrightarrow\quad z=py. \tag{1}
\]

Likewise, X lies on BE if and only if X=(1-\mu)B+\mu E for some real number \mu. The coordinates of this expression are
\[
x=\frac{\mu q}{1+q},\quad y=1-\mu,\quad z=\frac{\mu}{1+q}.
\]
Thus X\in BE implies x=qz. Conversely, if x+y+z=1 and x=qz, choose \mu=(1+q)z; then x=\mu q/(1+q) and y=1-x-z=1-(1+q)z=1-\mu. Hence
\[
X\in BE\quad\Longleftrightarrow\quad x=qz. \tag{2}
\]

Finally, X lies on CF if and only if X=(1-\nu)C+\nu F for some real number \nu. The coordinates of this expression are
\[
x=\frac{\nu}{1+r},\quad y=\frac{\nu r}{1+r},\quad z=1-\nu.
\]
Thus X\in CF implies y=rx. Conversely, if x+y+z=1 and y=rx, choose \nu=(1+r)x; then y=\nu r/(1+r) and z=1-x-y=1-(1+r)x=1-\nu. Hence
\[
X\in CF\quad\Longleftrightarrow\quad y=rx. \tag{3}
\]

Suppose first that AD,BE,CF are concurrent at a point P having normalized barycentric coordinates (x,y,z). Equations (1)--(3) give
\[
z=py,\qquad x=qz,\qquad y=rx.
\]
None of x,y,z is zero: if y=0, then z=py=0 and x=qz=0, contradicting x+y+z=1; if z=0 then x=qz=0 and y=rx=0, with the same contradiction; and if x=0 then y=rx=0 and z=py=0, again a contradiction. We may therefore divide, obtaining
\[
\frac{z}{y}=p,\qquad \frac{x}{z}=q,\qquad \frac{y}{x}=r.
\]
Multiplying these three equalities yields
\[
1=\frac{z}{y}\frac{x}{z}\frac{y}{x}=pqr
=\frac{BD}{DC}\frac{CE}{EA}\frac{AF}{FB}.
\]

Conversely, suppose pqr=1. Define S=qp+1+p, which is positive, and let P be the point with normalized barycentric coordinates
\[
(x,y,z)=\left(\frac{qp}{S},\frac{1}{S},\frac{p}{S}\right).
\]
These coordinates sum to 1, so the point exists and is unique; indeed all three coordinates are positive, so it lies in the interior of ABC. They satisfy
\[
z=py,\qquad x=qz,\qquad
rx=\frac{rqp}{S}=\frac{pqr}{S}=\frac1S=y.
\]
By (1), (2), and (3), respectively, P lies on AD, BE, and CF. Thus the three cevians are concurrent. This proves both implications.

## intuition
Normalized barycentric coordinates convert incidence with each cevian into one ratio between two coordinates. Three such ratios are simultaneously consistent exactly when their cyclic product is one.
