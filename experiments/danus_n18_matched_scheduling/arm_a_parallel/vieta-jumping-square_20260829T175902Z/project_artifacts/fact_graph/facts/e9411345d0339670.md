## statement
Let (a) and (b) be positive integers. Suppose that

\[
\frac{a^2+b^2}{ab+1}
\]

is an integer. Prove that this integer is a perfect square.

## proof
Let
\[
k=\frac{a^2+b^2}{ab+1}.
\]
The numerator and denominator are positive, so the assumed integer \(k\) is a positive integer. Equivalently,
\[
a^2+b^2=k(ab+1). \tag{1}
\]
Fix this value of \(k\). The set of ordered pairs of positive integers satisfying (1) is nonempty because it contains the given pair. Hence, by the well-ordering principle, choose from this set a pair whose coordinate sum is minimal. Since (1) is symmetric in its two coordinates, interchange the coordinates if necessary and denote this minimal pair again by \((a,b)\), with \(a\ge b\).

Define the integer
\[
c=kb-a.
\]
Rearranging (1) gives
\[
a(kb-a)=b^2-k,
\]
and therefore
\[
ac=b^2-k. \tag{2}
\]
We first prove that \(b^2\ge k\). Suppose instead that \(b^2<k\). Equation (2), together with \(a>0\), gives \(c<0\). Since \(c=kb-a\), this means \(a>kb\). All of \(a,k,b\) are integers, so
\[
a\ge kb+1 \quad\hbox{and}\quad a-kb\ge1.
\]
On the other hand, (1) can be written as
\[
0=a^2-kab+b^2-k=a(a-kb)+b^2-k.
\]
The preceding inequalities imply
\[
0=a(a-kb)+b^2-k
 \ge kb+1+b^2-k
 =k(b-1)+b^2+1>0,
\]
because \(k\ge1\) and \(b\ge1\). This contradiction proves \(b^2\ge k\).

If \(b^2=k\), then \(k=b^2\) is a perfect square, as required. It remains to rule out \(b^2>k\). In that case (2) gives
\[
c=\frac{b^2-k}{a}>0.
\]
Moreover,
\[
c=\frac{b^2-k}{a}<\frac{b^2}{a}\le b,
\]
where the final inequality uses \(a\ge b>0\). Thus \(c\) is a positive integer and \(c<b\le a\).

The identities \(a+c=kb\) and (2) now yield
\[
c^2-kbc+b^2-k
=c(c-kb)+b^2-k
=-ac+b^2-k=0.
\]
Consequently,
\[
c^2+b^2=k(cb+1),
\]
so \((c,b)\) is another pair of positive integers satisfying (1) for the same value of \(k\). But
\[
c+b<a+b
\]
because \(c<a\), contradicting the minimal choice of \((a,b)\). Therefore the case \(b^2>k\) is impossible. The only remaining case is \(k=b^2\), so the original integer is a perfect square.

## intuition
Choose a smallest positive solution for the fixed quotient. Replacing the larger coordinate by the other Vieta root either reaches zero, which identifies the quotient as a square, or produces a smaller positive solution; the only apparent negative-root case is excluded by an explicit integral inequality.
