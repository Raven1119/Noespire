## statement
Let \(Q\) be a real \(n\times n\) orthogonal matrix, and let \(u\in\mathbb R^n\) satisfy \(u^{\mathsf T}u=1\). Define
\[
H=I-2uu^{\mathsf T}.
\]
Assume there is no nonzero vector \(v\) with \(Qv=v\). Prove that there is a nonzero vector \(w\) with \(HQw=w\).

## proof
The assumption that there is no nonzero vector \(v\) satisfying \(Qv=v\) implies
\[
\ker(Q-I)=\{0\}.
\]
Because \(Q-I\) is a square \(n\times n\) matrix, it follows that \(Q-I\) is invertible. Define
\[
A=(Q-I)^{-1}
\quad\text{and}\quad
w=Au.
\]
The equality \(u^{\mathsf T}u=1\) implies \(u\ne0\). Since \(A\) is invertible, \(w=Au\ne0\).

It remains to prove that \(HQw=w\). Since \(Q\) is orthogonal, \(Q^{\mathsf T}=Q^{-1}\). Transposing the inverse defining \(A\) gives
\[
A^{\mathsf T}
=\bigl((Q-I)^{-1}\bigr)^{\mathsf T}
=(Q^{\mathsf T}-I)^{-1}
=(Q^{-1}-I)^{-1}.
\]
Moreover,
\[
Q^{-1}-I=-Q^{-1}(Q-I).
\]
Taking inverses of the two sides and respecting the order of the factors yields
\[
A^{\mathsf T}
=\bigl(-Q^{-1}(Q-I)\bigr)^{-1}
=-(Q-I)^{-1}Q
=-AQ.
\]
On the other hand, \(A(Q-I)=I\), so
\[
AQ-A=I
\quad\text{and hence}\quad
AQ=I+A.
\]
Consequently,
\[
A^{\mathsf T}=-I-A,
\qquad\text{so}\qquad
A+A^{\mathsf T}=-I.
\]
The quantity \(u^{\mathsf T}Au\) is a real scalar, and therefore it equals its transpose:
\[
u^{\mathsf T}Au=u^{\mathsf T}A^{\mathsf T}u.
\]
Thus
\[
2u^{\mathsf T}Au
=u^{\mathsf T}(A+A^{\mathsf T})u
=-u^{\mathsf T}u
=-1,
\]
which gives
\[
u^{\mathsf T}Au=-\frac12.
\]

The definition \(w=Au\) is equivalent to \((Q-I)w=u\), so
\[
Qw=w+u.
\]
Therefore
\[
u^{\mathsf T}Qw
=u^{\mathsf T}w+u^{\mathsf T}u
=u^{\mathsf T}Au+1
=-\frac12+1
=\frac12.
\]
Finally, using \(H=I-2uu^{\mathsf T}\), one obtains
\[
HQw
=(I-2uu^{\mathsf T})Qw
=Qw-2u(u^{\mathsf T}Qw)
=(w+u)-2u\left(\frac12\right)
=w.
\]
The vector \(w\) is nonzero and satisfies \(HQw=w\), as required.

## intuition
The inverse of Q-I is centered at -I/2 in the sense that A+A^{\mathsf T}=-I. This forces the scalar needed for the Householder correction to cancel exactly when w=Au.
