# Statement

For every integer n, the integer n³ - n is divisible by 2.

# Proof

Let n be any integer. We have n³ - n = n(n - 1)(n + 1). The integers n and n - 1 are consecutive, so one of them is even. Hence their product, and therefore n(n - 1)(n + 1) = n³ - n, is divisible by 2.
