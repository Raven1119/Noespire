# Statement

For every integer n, the integer n³ - n is divisible by 3.

# Proof

Let n be an integer. Modulo 3, n is congruent to 0, 1, or 2. If n ≡ 0 then 3 divides n; if n ≡ 1 then 3 divides n - 1; and if n ≡ 2 then 3 divides n + 1. Thus one of the factors n - 1, n, n + 1 is divisible by 3. Since n³ - n = n(n - 1)(n + 1), it is divisible by 3.
